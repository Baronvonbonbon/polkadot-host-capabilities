# Files, sharing and the clipboard

**Status (2026-09-19, codec 1, Android): files come in; nothing leaves as a file.** Reading a
picked file works. Downloads, file sharing, Web Share and print do nothing. Writing to the
clipboard works; reading from it is blocked.

| Path | Result |
|---|---|
| `<input type="file">` | works: a 4.5 MB PDF and a 1.5 MB PNG were read (almanac P4) |
| `showOpenFilePicker()` | works |
| `showSaveFilePicker()` / `showDirectoryPicker()` | rejected in 11 ms with "The user aborted a request". That is too fast for a person, so most likely no picker was shown. **Treat as unavailable** |
| `<a download>`, blob or data links | **do nothing** (almanac P4) |
| `navigator.share` (text, URL, files) | **absent** |
| `window.print()` | does nothing (almanac P4) |
| `navigator.clipboard.writeText` | works |
| `navigator.clipboard.readText` | **blocked**: "Read permission denied", even after the host granted `Clipboard` |

## What to do

- **Export by copying text.** almanac copies backups and the visit summary as text, and shows the
  text on screen in case the clipboard refuses.
- **Import by picking a file, or by pasting into a text field.** Pasting through the keyboard's own
  UI works where `readText()` doesn't.
- **Exchange between two phones with QR codes.** `BarcodeDetector` is built in on Android, and the
  camera works ([media-and-calls.md](media-and-calls.md)).
