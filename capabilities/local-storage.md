# Storage on the device

**Status (2026-09-19, codec 1, Android): use host local storage.** Web `localStorage` and OPFS also
work. IndexedDB and CacheStorage are absent, and cookies don't persist.

## Host local storage

The host keeps a store per product id. It holds strings, JSON and bytes.

```ts
import { getHostLocalStorage } from "@parity/product-sdk-host";
const store = await getHostLocalStorage();   // null outside the app
await store!.writeBytes("k", bytes);  await store!.readBytes("k");
await store!.writeJSON("j", obj);     await store!.readJSON("j");
await store!.writeString("s", "v");   await store!.readString("s");
await store!.clear("k");
```

- **Size:** one 4 MiB record was written and read back in 1.2–1.3 s (almanac P1).
- **Survives:** an app restart, and publishing a new build of the product (almanac P1). An update
  of the Polkadot app and a reinstall are **not measured yet**. Neither is whether the store is in
  phone backups (almanac P5).
- **Namespaced by product id.** Change the `.dot` label and the data is gone from the new name's
  point of view.
- An empty read may come back as a zero-length value. almanac treats empty as absent.

## Web storage inside the app

| API | Result |
|---|---|
| `localStorage` / `sessionStorage` | works |
| Origin Private File System | works (64 KiB written and read back) |
| IndexedDB | **absent**: `indexedDB` is undefined |
| CacheStorage | **absent** |
| Cookies | `document.cookie` writes don't persist, even though the document is top-level |
| `navigator.storage.persist()` | best-effort only (evictable) |

Libraries that assume IndexedDB (idb-keyval, Dexie, localForage's default driver, most wallet
SDKs' session stores) fail inside the app. Give them a host-storage adapter.
