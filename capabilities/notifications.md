# Notifications

**Status (2026-09-19, codec 1, Android): use the host's notification manager.** The web routes are
absent: `Notification`, service workers and `PushManager` don't exist in the app.

## Use it

```ts
import { getNotificationManager, requestDevicePermission } from "@parity/product-sdk-host";
await requestDevicePermission("Notifications");
const n = await getNotificationManager();                  // null when unavailable
// scheduledAt is a bigint (almanac passes BigInt(ms since epoch)); omit it to show now.
const id = await n!.push({ text: "Your order is ready", scheduledAt: BigInt(Date.now() + 120_000) });
await n!.cancel(id);
```

- **Scheduled notifications fire with the Polkadot app closed.** A reminder scheduled two minutes
  out arrived with the app closed, on two separate builds (almanac P3). That makes reminders
  possible without a server.
- A server can't reach a closed Product through web push, because there is none. No host call for
  server-sent push has been found or measured either.

## Don't

- **Don't feature-detect web push by `navigator.serviceWorker`.** The property exists, but
  registration throws "ServiceWorker is not available" and `PushManager` is absent. It is a
  half-implemented API: the check passes and the call fails. Detect `PushManager` and a successful
  registration, or skip web push inside the app.
