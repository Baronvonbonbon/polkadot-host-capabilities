# Network

**Status (2026-09-19, codec 1, Android): open.** `fetch` works same-origin, cross-origin (CORS)
and streaming. WebSocket to public RPC nodes works, and SSE and WebTransport are present.
`sendBeacon` is refused.

- **No content policy you can read.** The page has no CSP meta tag, and a header policy can't be
  read from script. almanac P10 found nothing blocked: the devnet IPFS gateway, People-chain and
  Bulletin RPC nodes were all reachable.
- **`navigator.sendBeacon` returns `false`**: the request is refused. Analytics and "flush on
  unload" code that relies on it silently loses data. Use `fetch(..., { keepalive: true })`, and
  test that it works.
- **The devnet IPFS gateway** (`https://devnet-ipfs.api.polkadotcommunity.foundation`) serves
  Bulletin content under both SHA-256 and BLAKE2b-256 CIDs, in about 400–600 ms. It serves
  Bulletin, not the public IPFS network.
- `navigator.connection` reports the link type (`4g`).
