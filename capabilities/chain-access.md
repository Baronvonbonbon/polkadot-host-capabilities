# Chain access

**Status (2026-09-19, codec 1, Android): mostly unmeasured through the host.** The probe that
should have measured it asked for a chain that doesn't exist (see Measured). A direct WebSocket
from the WebView works.

## The chains a devnet host carries

The Products devnet runs "Next" chains. A host build carries a fixed set of them. Each genesis
below was read off its own RPC with `chain_getBlockHash(0)` on 2026-09-19:

| Chain | Genesis | RPC |
|---|---|---|
| Paseo Asset Hub Next | `0x4349b00e54897e21196fd331015fc5be0f14e118beb0375ed2bb1793737bb57a` | `wss://paseo-asset-hub-next-rpc.polkadot.io` |
| Paseo People Next | `0x4a2b5b737de1da59e209b0000a876ec2fa20035dc34fd292a848da32d255ad48` | `wss://paseo-people-next-system-rpc.polkadot.io` |
| Paseo Bulletin Next | `0x8cfe6717dc4becfda2e13c488a1e2061ff2dfee96e7d031157f72d36716c0a22` | `wss://paseo-bulletin-next-rpc.polkadot.io` |
| Paseo Asset Hub (public testnet) | `0xd6eec26135305a8ad257a20d003357284c8aa03d0bdb2b357ab0a22371e11ef2` | `wss://asset-hub-paseo-rpc.n.dwellir.com` |

DotNS and FARE's contracts live on Paseo Asset Hub's EVM, `https://eth-rpc-testnet.polkadot.io/`,
chain id 420420417.

**`createApp`'s cloud storage environment must match the one you published under.** The SDK
defaults to `"paseo"`. A devnet host doesn't carry that Bulletin chain, so `createApp` throws
`Chain 0x8cfe6717… is not supported by the current host`, and everything that depends on storage
fails after it.

## Use it

```ts
import { getChainSpec, getHostProvider, isChainSupported } from "@parity/product-sdk-host";
const supported = await isChainSupported(genesis);   // Result<boolean>
const spec = await getChainSpec(genesis);            // Result<spec | null>; race it (see below)
const provider = await getHostProvider(genesis);     // a JSON-RPC provider routed by the host
```

- **Race every chain call against a deadline.** Asked about a genesis it doesn't carry, the host
  may never answer. It should say "not supported", and in the 2026-09-19 run it said nothing for
  45 s. See [pitfalls/host-calls-can-hang.md](../pitfalls/host-calls-can-hang.md).
- A direct `WebSocket` to a public RPC also works from inside the app. It connected to
  `wss://rpc.polkadot.io`, and almanac P10 reached People-chain nodes offering `statement_*` and
  Bulletin nodes. No content policy blocked it.
