# Payments

**Status (2026-09-19, codec 1, Android): not usable yet.** The host's payment manager exists, but
its balance subscription delivered nothing in 3 s, not even a zero. The web Payment Request API
is absent.

```ts
import { getPaymentManager } from "@parity/product-sdk-host";
const pm = await getPaymentManager();
const sub = pm!.subscribeBalance((b) => render(b));   // 2026-09-19: never called back
```

A Product can't show a balance or decide whether the user can afford something. Keep payments
out of the critical path, and handle funds with contracts the user signs for through the wallet
([identity-and-accounts.md](identity-and-accounts.md)).

**Not measured:** whether a balance ever arrives after more than 3 s. Nothing here has probed a
payment that moves funds.
