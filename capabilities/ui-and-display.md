# UI, display and graphics

**Status (2026-09-19, codec 1, Android):** Canvas 2D, WebGL 2, OffscreenCanvas in a worker, wake
lock, View Transitions and the VirtualKeyboard API work. Fullscreen is disabled, orientation lock is unavailable, and WebGPU has no
adapter. **AVIF doesn't decode.**

- **AVIF images render blank, with no error.** Serve WebP or JPEG.
- **Fullscreen is disabled** for the document (`fullscreenEnabled` is false), and
  `screen.orientation.lock()` is unavailable. The host owns the chrome.
- **Screen Wake Lock works.** It is useful for a screen showing a QR code, or a driver's
  navigation view.
- **WebGL 2** works (OpenGL ES 3.0), and so does rendering to an **OffscreenCanvas in a worker**.
- **WebGPU:** `navigator.gpu` exists, but `requestAdapter()` returns `null`.
- **Speech:** recognition is present. `speechSynthesis` is absent.
- **Contact Picker** is present but throws "Unable to open a contact selector". **Idle Detection**
  is denied.
- `navigator.userAgentData` high-entropy hints give the device model.
